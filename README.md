# Job Portal & Applicant Tracking System

A full-stack recruitment platform built with React.js, Django REST
Framework, and MySQL.

## Project Overview

The platform connects candidates, recruiters, and administrators.

### Candidate Features

- Account registration and authentication
- Candidate profile and resume management
- Job search and filtering
- Job applications and application tracking
- Application status notifications

### Recruiter Features

- Recruiter profiles
- Job creation and management
- Applicant review
- Application status management
- Recruitment statistics

### Admin Features

- User and account management
- Job listing moderation
- Platform statistics

## Technology Stack

### Frontend

- React.js
- Vite
- JavaScript
- React Router
- Axios
- Bootstrap or custom CSS

### Backend

- Python
- Django
- Django REST Framework
- Django REST Framework Simple JWT
- Django CORS Headers

### Database

- MySQL

### Development Tools

- Git and GitHub
- Visual Studio Code
- Postman
- Swagger/OpenAPI
- Django automated tests
